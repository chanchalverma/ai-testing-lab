# AI Testing Lab

A hands-on **AI Quality Engineering / AI SDET** repository for building
and testing GenAI applications.

This project starts with **LLM chatbot testing** and will gradually
expand into **AI Agent testing, RAG testing, MCP-based workflows, and
other AI evaluation techniques**.

## Project Goals

The goal of this repository is to learn and implement practical AI
testing patterns using real LLM applications rather than only
theoretical examples.

The repository will cover:

-   LLM / chatbot testing
-   Conversational AI testing
-   LLM evaluation with DeepEval
-   AI Agent testing
-   Agent tool/function-call validation
-   RAG evaluation
-   MCP testing
-   Hallucination detection
-   Context and memory testing
-   Relevance and correctness evaluation
-   AI security testing
-   Automated AI tests in CI/CD

## Current Stack

-   **Python**
-   **Google Gemini API**
-   **DeepEval**
-   **pytest**
-   **python-dotenv**

Additional tools and frameworks will be added as the project grows.

## 1. Chatbot Testing

The first part of the project focuses on a real Gemini chatbot.

The chatbot can maintain a conversation using Gemini's chat API:

``` text
User
 ↓
Gemini Chatbot
 ↓
Response
 ↓
User follow-up
 ↓
Gemini uses conversation context
```

### Example

``` text
You: What is Playwright?

Gemini: Playwright is an end-to-end browser automation framework...

You: I know JavaScript. Show me an example.

Gemini: Sure, here is a JavaScript example...
```

## 2. LLM Evaluation with DeepEval

DeepEval is used as the evaluation framework.

The project currently demonstrates:

### Single-turn evaluation

Using `LLMTestCase`:

``` text
Question
   ↓
Gemini
   ↓
Actual response
   ↓
DeepEval
   ↓
Evaluation metric
```

Example metrics include:

-   Answer Relevancy
-   Correctness
-   Faithfulness
-   Hallucination-related evaluation

### Conversational evaluation

Using `ConversationalTestCase`:

``` text
User question
      ↓
Gemini response
      ↓
User follow-up
      ↓
Gemini response
      ↓
Conversation evaluation
```

This allows testing:

-   Turn relevancy
-   Knowledge/context retention
-   Conversation completeness
-   Multi-turn behavior

## 3. Environment Setup

### Clone the repository

``` bash
git clone <repository-url>
cd ai-testing-lab
```

### Create a virtual environment

Windows PowerShell:

``` powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### Install dependencies

``` powershell
pip install -r requirements.txt
```

### Configure API keys

Create a `.env` file in the repository root:

``` env
GEMINI_API_KEY=your_gemini_api_key
GOOGLE_API_KEY=your_gemini_api_key
```

Never commit `.env` to Git.

The `.gitignore` file should contain:

``` gitignore
.env
.venv/
__pycache__/
*.pyc
.pytest_cache/
```

## 4. Running the Chatbot

Run:

``` powershell
python chatbot/chatbot.py
```

Example:

``` text
Gemini Dynamic Chatbot
Type 'exit' to quit.

You: What is AI testing?

Gemini: ...
```

## 5. Running LLM Evaluation

Run the single-turn evaluation:

``` powershell
python testcases/eval_chatbot.py
```

DeepEval evaluates the actual response generated by Gemini.

The evaluation model can be configured with:

``` powershell
deepeval set-gemini --model=<gemini-model>
```

## 6. Conversational Testing

Run:

``` powershell
python testcases/conversational_test.py
```

A conversational test captures multiple user and assistant turns and
evaluates the conversation as a whole.

The important distinction is:

-   `LLMTestCase` → one LLM interaction
-   `ConversationalTestCase` → multiple related interactions
